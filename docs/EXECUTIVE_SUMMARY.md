## Overview

**EEGSuite** is an integrated software platform that synchronizes brain imaging (EEG) with tactile stimulation to advance understanding of sensory processing and neuromotor control. Designed specifically for Parkinson's disease research, it solves a critical technical challenge: isolating true neural responses from electromagnetic noise generated by stimulation devices.

The platform enables rigorous, publication-ready neuroscience research with minimal technical overhead.

---

## The Problem It Solves

### Vibrotactile Research Challenge

When investigating how the brain responds to vibrations applied to the skin, researchers face a fundamental problem: the measuring equipment (EEG sensors) picks up **two signals simultaneously:**

1. **The neural response we want to measure** (small, subtle brain activity)
2. **Electromagnetic radiation from the vibration device** (strong, overwhelming noise at the exact same frequency)

Conventional filtering cannot separate these signals because they occur at **identical frequencies**.

### Current Industry Approaches

- **Approach 1:** Use shielded rooms and expensive electromagnetically-isolated equipment (cost: $100K+)
- **Approach 2:** Accept poor signal quality and weak conclusions
- **Approach 3:** Abandon the research direction entirely

### EEGSuite's Solution

**The FOT/IFNFN Contrast Method**

Record two identical conditions that differ only in physical contact:

| Condition | Setup | Measures |
|-----------|-------|----------|
| **FOT** (Finger On Tactor) | Subject touching the device | Neural response + Electromagnetic noise + Background |
| **IFNFN** (In-Field No Feeling) | Device active 1mm away from contact | Electromagnetic noise + Background (no neural signal) |
| **Contrast (FOT − IFNFN)** | Mathematically subtract the two | **Pure neural response** (noise cancels out) |

This approach requires **no expensive hardware modifications**, achieves **3–6× signal improvement**, and is **scientifically rigorous**.

## Key Capabilities

### 1. **Real-Time Data Acquisition**
- Streams EEG data from 32-channel bioamplifiers at 1000 samples/second
- Synchronizes with vibrotactile stimulation device
- Enables real-time monitoring and live quality assessment
- Works across multiple networked computers

### 2. **Structured Experimental Protocols**
- Automated "Sweep Protocol" iterates through stimulus frequencies, amplitudes, and body locations
- Automatic artifact baseline recording
- Event markers synchronized with EEG
- Saves raw data in industry-standard formats

### 3. **Automated Data Preprocessing**
- Removes 50/60 Hz mains interference and harmonics
- Detects and interpolates bad electrode channels
- Applies reference signal optimization (linked ears or Laplacian)
- Handles both high-quality electrode montages and minimal setups

### 4. **Advanced Analysis Methods**
- **Time-Frequency Analysis:** Visualizes how brain activity changes across frequencies and over time
- **Topographic Mapping:** Shows spatial distribution of neural responses across the scalp
- **Contrast Analysis:** Isolates pure neural response via FOT/IFNFN subtraction (proprietary method)
- **Artifact Rejection:** Automatically removes noisy trials caused by muscle twitches, eye blinks, or tremors

### 5. **Publication-Ready Reports**
- Interactive HTML reports with professional visualizations
- Detailed preprocessing history and quality metrics
- Statistical comparisons and effect sizes
- Data export in multiple formats (CSV, MNE FIF) for external analysis

## System Architecture

### Distributed Acquisition Model

The system consists of three independent roles:

```
┌─────────────────────────────────────┐
│  Acquisition Computer               │
│  - Connected to EEG amplifier      │
│  - Runs LSL Server                 │
│  - Handles real-time streaming     │
└──────────────┬──────────────────────┘
               │ Gigabit Ethernet (LSL protocol)
               │
┌──────────────▼──────────────────────┐
│  Control Computer                   │
│  - Executes experimental protocol  │
│  - Manages stimulus device          │
│  - Records and timestamps data     │
└──────────────┬──────────────────────┘
               │
┌──────────────▼──────────────────────┐
│  Analysis Computer (optional)       │
│  - Offline processing              │
│  - Report generation               │
│  - Data visualization              │
└─────────────────────────────────────┘
```

**Benefits:**
- Separation of concerns (specialized hardware per role)
- Minimal computational load on acquisition computer
- Flexible deployment (all on one machine or distributed)
- Easy to add monitoring nodes without affecting data quality

## Workflow: From Data Acquisition to Results

```
PHASE 1: SETUP
  ├─ Install software (Conda: 5 minutes)
  ├─ Configure hardware (YAML files: 10 minutes)
  └─ Test LSL stream (2 minutes)

PHASE 2: EXPERIMENTAL EXECUTION
  ├─ Start LSL server
  ├─ Execute Sweep Protocol (typically 10–30 minutes per subject)
  ├─ Automatically saves timestamped EEG + markers to CSV
  └─ Optional: Real-time visualization

PHASE 3: DATA PROCESSING
  ├─ Convert CSV to standard MNE format (1 second)
  ├─ Preprocessing pipeline (10–30 seconds)
  │  ├─ Notch filter (50 Hz)
  │  ├─ Reference signal optimization
  │  └─ Bad channel detection/interpolation
  └─ Generates preprocessed data file

PHASE 4: ANALYSIS & REPORTING
  ├─ Choose analysis mode:
  │  ├─ Single-condition: TFR + PSD + topomaps
  │  └─ Contrast: FOT vs. IFNFN subtraction
  ├─ Automatic artifact rejection (>200µV threshold)
  ├─ Baseline normalization (dB or percent change)
  └─ Generate publication-ready HTML report

DELIVERABLES
  ├─ Interactive HTML report (view in any browser)
  ├─ CSV data export (import to MATLAB, R, Python)
  ├─ MNE FIF files (compatible with EEGLAB, FieldTrip, etc.)
  └─ Metadata & processing history
```

**Total time per subject:** 45–90 minutes (including acquisition, processing, and analysis)

## Frequently Asked Questions (Technical Parties)

### Q: Why use LSL instead of direct USB acquisition?
**A:** LSL enables network streaming and multi-node monitoring without custom drivers. Decouples hardware from analysis software.

### Q: What's the latency from stimulus to recorded marker?
**A:** Typically <10 ms (LSL + USB latency). Sufficient for neuroscience research. Not real-time neurofeedback (would require <1 ms).

### Q: Can I analyze data from other EEG devices?
**A:** Yes, if you can convert to CSV format. FREG32, BrainFlow-compatible devices, or any system with CSV export supported.

### Q: How do you handle missing bad channels?
**A:** Spherical spline interpolation (if montage provided) or SimplePrep (bandpass + average reference) fallback.

### Q: What's the computational overhead of contrast analysis vs. single-condition?
**A:** ~2–3× longer processing time (must analyze FOT + IFNFN separately, then subtract). Still <45 seconds total per file.

### Q: Can I export results to MATLAB/R/Python for custom analysis?
**A:** Yes. CSV exports, MNE FIF files (Python-native), or raw HDF5. Full data pipeline transparency.

### Q: What if my electrode montage is non-standard?
**A:** SimplePrep fallback works without montage coordinates. Or upload custom montage YAML. Full flexibility.

## Getting Started: 3-Step Quick Start

### Step 1: Installation (5 minutes)
```bash
conda create -c conda-forge -n f2heal mne
conda activate f2heal
git clone https://github.com/F2HEAL/EEGsuite.git
cd EEGsuite
pip install -e .
```

### Step 2: Configuration (10 minutes)
Create three YAML files:
1. `config/hardware/your_device.yaml` (sampling rate, channels, serial port)
2. `config/montages/your_montage.yaml` (channel names & 10-20 locations)
3. `config/protocols/your_protocol.yaml` (stimulus frequency/amplitude/duration)

### Step 3: Acquire Data (30 minutes + session time)
```bash
# Terminal 1: Start EEG streaming
python -m src.main LSLserver -c config/hardware/your_device.yaml

# Terminal 2: Run experimental protocol
python -m src.main sweep -p config/protocols/your_protocol.yaml -d config/hardware/your_device.yaml

# After session: Process & analyze
python -m src.main convert -f data/raw/your_file.csv -c config/montages/your_montage.yaml
python -m src.main analyze_contrast --fot data/raw/fot_file.fif.gz --ifnfn data/raw/ifnfn_file.fif.gz
```

Generated reports automatically appear in `reports/`.
